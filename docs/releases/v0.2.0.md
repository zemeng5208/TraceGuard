# TraceGuard 0.2.0 pre-release notes / 预发布说明

> **Status: pre-release candidate; not a stable release.**  
> **状态：预发布候选版本，并非稳定正式版。**

Release date / 发布日期: Unreleased / 尚未发布

## What this build is / 版本定位

TraceGuard `0.2.0` is the first package-complete MVP candidate. It connects the bilingual Electron/React desktop experience to the local .NET 8 Windows observation Core and SQLite persistence, while preserving the Zero-Privilege, CoreGuard, and Local First boundaries.

TraceGuard `0.2.0` 是首个完成成品打包链路的 MVP 候选版本。它把双语 Electron/React 桌面界面、本地 .NET 8 Windows 观察 Core 与 SQLite 持久化连接起来，同时严格保持 Zero-Privilege、CoreGuard 与 Local First 边界。

## Highlights / 主要内容

- Full Console, structured Live Terminal, Floating Widget, Floating Bubble, tray integration, and centralized Settings.
- Runtime English/Simplified Chinese switching, including native tray and floating-surface text.
- Real process, service, resource, startup, registry, browser-configuration, network-configuration, default-app, and Windows Update observation where the current user can read them.
- Installer sessions, parent/child launch chains, selected HKCU before/after diffs, severity-aware local reports, and JSON report export.
- Current-user startup disable/restore and Block Auto-Restart rules with current-token permission checks.
- Metadata-only file monitoring through user-folder `FileSystemWatcher`, eligible read-only NTFS USN tailing, and optional exact-path user-mode ETW attribution.
- CoreGuard permanently denies destructive actions against protected Windows components.
- Local SQLite events, reports, rules, and atomic versioned settings; no telemetry or cloud dependency.

- 完整主控制台、结构化实时终端、悬浮窗、悬浮球、托盘集成和集中式 Settings。
- 英文/简体中文运行时切换，包括原生托盘与悬浮界面文字。
- 在当前用户可读范围内，观察真实进程、服务、资源、自启动、注册表、浏览器配置、网络配置、默认应用和 Windows Update 活动。
- 安装程序会话、父子进程启动链、选定 HKCU 前后差分、分级本地报告和 JSON 报告导出。
- 当前用户级启动项禁用/恢复，以及带当前令牌权限检查的 Block Auto-Restart 规则。
- 通过用户目录 `FileSystemWatcher`、符合条件的只读 NTFS USN 增量读取和可选用户态 ETW 精确路径归属完成仅元数据文件监控。
- CoreGuard 永久禁止对受保护 Windows 核心组件执行危险操作。
- 本地 SQLite 事件/报告/规则与原子版本化设置；无遥测，不依赖云端。

## Artifacts and installation / 成品与安装

This candidate is intended to ship as x64-only:

- `TraceGuard-Setup-0.2.0-x64.exe` — per-user NSIS installer, `asInvoker`, no UAC request.
- `TraceGuard-Portable-0.2.0-x64.exe` — self-extracting portable application running as the current user.
- `SHA256SUMS.txt` — SHA-256 values generated after package validation.

候选版本当前仅提供 x64：当前用户 NSIS 安装包、当前用户 Portable 包，以及完成成品校验后生成的 `SHA256SUMS.txt`。请按 [README](../../README.md#install-run-verify-and-uninstall) 校验 SHA-256 后再运行。

The executables are not code-signed. Windows SmartScreen may display an unknown-publisher warning. Only continue when the file came from the TraceGuard repository release and its checksum matches.

可执行文件尚未进行代码签名，Windows SmartScreen 可能显示未知发布者。仅在文件来自 TraceGuard 仓库 Release 且校验值一致时继续。

## Known limitations / 已知限制

- TraceGuard never requests administrator permission. Protected processes, elevated services, and machine-level settings may be observable but not controllable.
- USN access depends on an existing readable NTFS journal; denied or non-NTFS volumes fall back to `FileSystemWatcher`.
- Exact process attribution is available only for exact-path matches seen by an optional eligible user-mode ETW session. Remaining file/session attribution is explicitly best-effort.
- Disk/process totals can omit elevated or protected processes unreadable by the current token.
- Browser monitoring observes selected configuration changes only. It does not read passwords, cookies, form data, or browsing-history content.
- Local data is stored under `%LOCALAPPDATA%\TraceGuard` and is not intentionally deleted by an ordinary uninstall.
- The final packaged light/dark visual review and consumer-hardware compatibility matrix are not yet complete.

- TraceGuard 永不请求管理员权限；受保护进程、高权限服务和机器级设置可能只能观察，不能控制。
- USN 能力取决于现有且当前用户可读的 NTFS 日志；无权限或非 NTFS 卷会回退至 `FileSystemWatcher`。
- 仅对可选且有资格启动的用户态 ETW 会话所捕获的精确路径匹配提供进程归属；其余文件/会话归属会明确标记为尽力判断。
- 当前令牌无法读取的高权限或受保护进程可能不会计入磁盘/进程汇总。
- 浏览器监控只观察选定配置变化，不读取密码、Cookie、表单数据或浏览历史正文。
- 本地数据存储于 `%LOCALAPPDATA%\TraceGuard`，普通卸载不会主动删除这些数据。
- 最终打包版明暗主题视觉复核及消费级实机兼容矩阵尚未完成。
